# NetSentry v2 — Production Network Intrusion Detection System

## 📁 Repository Layout
- `configs/`: Declarative YAML configurations (models, search spaces, pipelines).
- `data/`: Local storage for raw and processed network traffic datasets (gitignored).
- `netsentry/`: Core Python package (pipeline, feature engineering, serving).
- `tests/`: Automated unit, integration, and stress tests.
- `notebooks/`: Exploratory analysis and rapid prototyping only.
- `scripts/`: CLI entrypoints and orchestration runners.
- `docker/`: Dockerfiles and containerization assets.
- `.github/`: CI/CD workflows and automation pipelines.
